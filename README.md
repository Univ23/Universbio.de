# Univers Bio – Website Starter

Dies ist die Starter-Webseite für den Bioladen **Univers Bio**.

## Inhalte
- `index.html` – Hauptseite
- `styles.css` – Design
- `script.js` – kleine Funktionen
- `assets/logo.svg` – Logo
- `assets/favicon.svg` – Favicon

## Lokal testen
1. Alle Dateien in einem Ordner speichern (`univers-bio-site`).
2. Doppelklick auf `index.html` → öffnet die Seite im Browser.

## Online stellen (GitHub Pages)
1. Repository auf [GitHub](https://github.com) erstellen.
2. Dateien hochladen.
3. In den Repo-Einstellungen → **Pages** aktivieren.
4. Die Seite ist dann erreichbar unter:  
   `https://DEIN-NAME.github.io/univers-bio-site/`

## Nächste Schritte
